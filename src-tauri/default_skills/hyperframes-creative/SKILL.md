# HyperFrames Creative

Non-animation creative direction for HyperFrames videos.

## Scope

- Design spec handling (`frame.md` / `design.md`).
- Palettes and typography.
- Narration and beat planning.
- Audio-reactive visuals and composition patterns.
- Brand and style decisions.

For atomic motion patterns and scene blueprints, use `hyperframes-animation`.
