# HyperFrames Studio

Collaborating with a person on a HyperFrames project in Studio.

## Decide first

Ask whether the message requests a change at all. Questions, loose ideas, and
"don't change anything" get an answer and a plan, not an edit.

## New film

Produce a plan, a storyboard, and a build order.

## Timeline layout

- One caption track.
- One element kind per track.
- Every scene a sub-composition.
- Respect safe zones for captions and key content.
