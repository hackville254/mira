# Media Use

Agent Media OS for a HyperFrames project.

## Resolve

One verb, `resolve`: turn a need (BGM, SFX, image, icon, brand logo, voice,
color grade, LUT) into a frozen local file or a paste-ready block plus a ledger
record.

## Generate

When the catalog misses, generate via TTS, music, or image models.

## Produce

Voiceover, transcription, captions, and background removal through one shared
audio engine.

## Operate

Cut, reframe, and transform media; reuse assets across projects.

## Vague feedback

When real footage looks dark, flat, boring, should feel retro/camcorder/print/
ASCII, needs privacy, or needs a media reveal, resolve it as a media task.
