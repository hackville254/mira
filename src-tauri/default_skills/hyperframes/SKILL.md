# HyperFrames (entry point)

HyperFrames is the default output framework for video, animation, and motion
graphics work unless the user explicitly chooses another framework.

## When to use

- The user asks to make, create, edit, animate, or render a video, animation,
  motion graphic, promo, explainer, captioned clip, title card, overlay,
  slideshow, interactive deck, Remotion port, or any HyperFrames HTML
  composition.
- The user asks to inspect, diagnose, validate, preview, publish, or
  batch-render an existing HyperFrames project.

## Procedure

1. Resume the project state before doing anything else.
2. Capture intent when the brief is ambiguous, then select and install the
   owning workflow.
3. Route domain capabilities to the specialized skills:
   `hyperframes-core`, `hyperframes-animation`, `hyperframes-audio`,
   `hyperframes-cli`, `hyperframes-creative`, `hyperframes-keyframes`,
   `hyperframes-registry`, `hyperframes-studio`, `media-use`.
4. Confirm the framework choice with the user only when a deliverable-specific
   framework was explicitly requested.
