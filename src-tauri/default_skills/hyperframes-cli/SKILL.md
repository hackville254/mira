# HyperFrames CLI

The development loop for HyperFrames projects.

## Common commands

- `init`, `add`, `catalog` - project setup and registry installs.
- `capture`, `lint`, `check` - inspect and validate.
- `snapshot`, `compare`, `grade-compare` - visual diffing.
- `preview`, `play`, `present` - local preview.
- `beats`, `keyframes`, `timeline`, `compositions` - inspect timing.
- `render` (single or batch), `publish`, `cloud`, `cloudrun`, `lambda` - output.
- `doctor`, `browser`, `info`, `upgrade` - diagnostics.
- `clean`, `docs`, `benchmark`, `telemetry`, `transcribe`, `auth`, `tts`,
  `remove-background` - utilities.

`validate`, `inspect`, and `layout` are deprecated aliases; use `check`.
