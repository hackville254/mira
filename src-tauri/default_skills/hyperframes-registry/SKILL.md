# HyperFrames Registry

Search, install, and wire registry blocks and components.

## When to use

Before hand-building any named visual: CRT scanlines, glitch, chromatic
aberration, film grain, shimmer sweep, charts, code or terminal windows, maps,
confetti bursts. Roughly 400 hosted items already cover many of them and the
search ranks all of them with nothing installed and no account.

## Workflow

1. Search the catalog first.
2. Install the matching block or component.
3. Wire it into `index.html` following the block sub-composition pattern.
4. Merge component snippets when the item is a component.
